# 尺码指南

## 服装尺码
- S 码：胸围 86-91cm，适合 160-165cm 身高
- M 码：胸围 91-96cm，适合 165-170cm 身高
- L 码：胸围 96-101cm，适合 170-175cm 身高
- XL 码：胸围 101-107cm，适合 175-180cm 身高

## 鞋子尺码
- 欧码 39 = 美码 7 = 脚长 24.5cm
- 欧码 41 = 美码 8.5 = 脚长 26cm
- 欧码 43 = 美码 10 = 脚长 27.5cm
- 建议下午测量脚长，运动后脚部会略微膨胀

## 尺码测量方法
- 胸围：沿胸部最丰满处水平测量一周
- 腰围：沿腰部最细处水平测量一周
- 裤长：从腰头到裤脚沿内侧测量

## 尺码选择建议
- 修身版型建议按日常尺码选择
- 宽松版型可考虑小一码
- 两个尺码之间犹豫时，建议选大一码
- 商品详情页的尺码表为人工测量，存在 1-2cm 误差属正常

## 特殊尺码
- 大码系列（2XL-5XL）独立尺码表，以商品页为准
- 童装按年龄和身高双维度标注
- 定制尺寸商品不参与退换（见退货政策）
