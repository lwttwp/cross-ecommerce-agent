# 国际订单政策

## 可配送国家
- 支持配送至 40+ 国家和地区，包括美加、欧洲、日韩、东南亚、澳新
- 暂不支持配送至非洲、南美部分国家和战乱地区
- 具体可配送范围以下单时地址校验为准

## 限制与禁运品
- 禁止邮寄液体、粉末、电池（单独运输的）、管制刀具
- 电子产品中的锂电池需符合航空运输规定
- 违反禁运规定被海关扣留的包裹，损失由客户承担

## 关税与税费
- 美加英德订单关税由我方承担（见物流政策）
- 欧盟地区订单 VAT 在下单时直接结算
- 其他地区关税由客户在清关时向当地海关缴纳

## 地址填写规范
- 收货地址必须使用拉丁字母填写
- 地址需包含门牌号、街道、城市、州/省、邮编、国家
- 邮编错误可能导致包裹延误或退回，请仔细核对

## 国际退换注意事项
- 国际退货需使用可追踪的物流方式寄回
- 退回包裹请附上原订单号和退货原因
- 国际退货运费承担规则与国内订单一致（见退货政策）
