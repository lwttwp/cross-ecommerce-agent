# 商品使用保养指南

## 服饰类保养
- 棉质衣物建议 30°C 以下水温机洗，深色衣物单独洗涤
- 羊毛制品建议干洗，不可机洗和烘干
- 羽绒服使用中性洗涤剂，洗后自然晾干并拍打蓬松

## 电子产品保养
- 充电时避免覆盖设备，防止过热
- 锂电池建议电量保持在 20%-80% 区间
- 长期不用时每月充放电一次，防止电池休眠

## 家居用品保养
- 实木家具避免阳光直射和潮湿环境
- 不锈钢制品使用软布清洁，避免钢丝球划伤
- 纺织品类（地毯、抱枕）定期吸尘，可局部手洗

## 户外用品保养
- 帐篷使用后彻底晾干再收纳，防止发霉
- 登山鞋定期清洁并涂抹防水喷雾
- 睡袋建议悬挂存放，保持蓬松度

## 通用注意事项
- 所有电器产品请使用原装或认证充电器
- 清洁前先阅读商品附带的保养说明卡
- 因保养不当造成的损坏不在质保范围内（见质保政策）
