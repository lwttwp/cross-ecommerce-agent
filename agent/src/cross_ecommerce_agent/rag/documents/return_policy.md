# 退货政策

## 无理由退货
- 支持 7 天无理由退货，从客户签收之日起计算
- 商品须保持完好、未使用、吊牌完整，不影响二次销售
- 无理由退货由客户承担退货运费

## 质量问题退货
- 签收后 30 天内发现质量问题（破损、功能故障、发错货），可申请退货或换货
- 质量问题退货由我方承担退货运费，客户无需支付任何费用
- 需提供商品照片或视频作为质量问题的证明材料

## 退款时效
- 退货包裹签收并验货通过后，3 个工作日内发起退款
- 退款按订单原支付方式原路退回，到账时间以支付渠道为准（3-10 个工作日）
- 使用优惠券的订单，退款金额按实付金额计算，优惠券不予退还

## 不可退货商品
- 定制类商品（刻字、定制尺寸）不支持无理由退货
- 贴身衣物（内衣、袜类）拆封后不支持退货
- 已使用或已清洗的商品不支持退货

## 退货流程
- 客户在订单详情页发起退货申请，填写原因并上传凭证
- 审核通过后获得退货地址，客户 7 天内寄出
- 退货单号回填后进入物流跟踪，签收后自动进入验货流程
