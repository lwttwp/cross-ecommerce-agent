# 礼品卡政策

## 礼品卡购买
- 礼品卡面值可选 $25、$50、$100、$200
- 购买礼品卡可使用优惠券抵扣
- 礼品卡支付部分不产生积分

## 礼品卡使用
- 每笔订单可使用多张礼品卡，与积分不可同时使用
- 礼品卡余额不足时，剩余金额使用其他支付方式补足
- 礼品卡不设有效期，长期有效

## 礼品卡余额查询
- 在账户中心「我的礼品卡」查看余额和使用记录
- 礼品卡售出不支持退货退款
- 礼品卡丢失不挂失、不补办，请妥善保管卡号和密码

## 赠送与转让
- 礼品卡可通过邮箱赠送给他人，赠送后不可撤回
- 礼品卡密码泄露导致被盗刷，责任由持卡人承担
- 禁止在第三方平台转售礼品卡，违者账户封禁
